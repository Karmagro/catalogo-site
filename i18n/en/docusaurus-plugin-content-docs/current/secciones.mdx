# Components by Digital Board Section

The matrix shows which components of the catalog relate to each of the six sections of the Digital Board, and in what way: mandatory, optional, or no relationship.

A **mandatory** relationship means that the component always touches that section through its essential capabilities. An **optional** relationship indicates that it touches the section only when it incorporates certain additional capabilities. An empty cell means that the component does not relate to that section, either in its mandatory form or in its documented optional variants.

## How to read the matrix {/* #como-leer-la-matriz */}

It answers questions such as:

- *Which components update system data through human operators?* → Check the **Manual Upd.** column
- *Which components produce automatic outputs?* → Check the **Automatic Out.** column
- *Which sections of the board does a Dashboard touch?* → Follow the **Dashboard** row.
