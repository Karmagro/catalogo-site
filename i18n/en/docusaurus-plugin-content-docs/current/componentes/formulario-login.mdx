## Description {/* #descripcion */}

A component that lets human users identify themselves to the system through a web interface in order to access personalized functionality. The system presents an identification form, validates the supplied credentials against a user base, and establishes an authenticated session that allows the user to interact with the system.

- Presents a graphical web interface (HTML form, login page) for the user to enter their credentials
- Verifies the credentials against a user repository (local database or external identity provider)
- Establishes an authenticated session through cookies, JWT tokens, or similar mechanisms
- Gives the user feedback on the result of the authentication (success, error, locked account)

## Additional capabilities {/* #capacidades-adicionales */}

<div className={styles.capBlockOptional}>

<div className={styles.capHeading}>
  <svg viewBox="0 0 16 16" width="16" height="16" fill="currentColor"><path d="M8 1a7 7 0 1 1 0 14A7 7 0 0 1 8 1zm.5 3.5a.5.5 0 0 0-1 0V7.5H4.5a.5.5 0 0 0 0 1H7.5v3a.5.5 0 0 0 1 0V8.5h3a.5.5 0 0 0 0-1H8.5V4.5z"/></svg>
  <span>Additional capabilities</span>
</div>

- **Remember me:** keeps the session open between visits through long-lived cookies, so that the user does not have to re-enter credentials on every access
- **Access recovery:** lets users who forgot their password recover it through a flow that is reachable without prior authentication, typically by sending a link or code by email
- **Lockout after failed attempts:** temporarily restricts access after multiple consecutive failed attempts, mitigating brute-force attacks
- **Anti-bot CAPTCHA:** adds challenges to tell human users apart from automated bots

</div>

## Variants {/* #modalidades */}

- **Traditional username + password:** a form that asks for a username or email and a password
- **Single Sign-On (SSO):** delegation of authentication to external providers such as Google, Microsoft, or Facebook
- **Two-factor authentication (2FA):** requires a second factor in addition to the password (OTP code, SMS)
- **Magic link / Passwordless:** a one-time link sent by email that authenticates without a password

## Typical dependencies {/* #dependencias-tipicas */}
