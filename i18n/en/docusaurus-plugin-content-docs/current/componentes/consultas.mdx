## Description {/* #descripcion */}

A component that lets users retrieve specific information from the system through defined search criteria. Its purpose is to provide fast, targeted access to existing data, filtering the contents of the repository according to parameters supplied by the user.

## Mandatory capabilities {/* #capacidades-mandatorias */}

<div className={styles.capBlockMandatory}>

<div className={styles.capHeading}>
  <svg viewBox="0 0 16 16" width="16" height="16" fill="currentColor"><path d="M8 1a7 7 0 1 1 0 14A7 7 0 0 1 8 1zm3.36 4.65a.5.5 0 0 0-.72-.01L7.3 9.28 5.36 7.34a.5.5 0 1 0-.72.7l2.25 2.25a.5.5 0 0 0 .72 0l3.75-3.75a.5.5 0 0 0 0-.7z"/></svg>
  <span>Mandatory capabilities</span>
</div>

- Allows the user to specify search criteria through fields, filters, or parameters
- Retrieves the records in the repository that match the criteria, without transforming or aggregating them
- Returns the results in a format the requesting user or system can interpret

</div>

## Additional capabilities {/* #capacidades-adicionales */}

<div className={styles.capBlockOptional}>

<div className={styles.capHeading}>
  <svg viewBox="0 0 16 16" width="16" height="16" fill="currentColor"><path d="M8 1a7 7 0 1 1 0 14A7 7 0 0 1 8 1zm.5 3.5a.5.5 0 0 0-1 0V7.5H4.5a.5.5 0 0 0 0 1H7.5v3a.5.5 0 0 0 1 0V8.5h3a.5.5 0 0 0 0-1H8.5V4.5z"/></svg>
  <span>Additional capabilities</span>
</div>

- **Advanced search with combinable filters:** narrows the search through multiple simultaneous criteria (date range, category, author, etc.) in addition to free text
- **Combining data from multiple sources:** retrieves information that requires relating data from different entities or repositories of the system
- **Result export:** lets the user download the records found as a file (CSV, Excel, JSON), keeping the raw data without aggregations
- **Pagination:** splits the results into pages to handle large volumes without overloading the interface
- **Autocomplete and suggestions:** proposes terms or records as the user types
- **Search history:** records the user's previous queries and allows reusing them

</div>

## Boundaries {/* #delimitaciones */}

<Admonition type="danger" title="What it is not">

- **Does not** process or transform the extracted data: it returns the records exactly as they are stored in the repository
- If it includes export, it exports the filtered raw data, without aggregate calculations
- **Does not** present indicators or graphical visualizations — that belongs to [Dashboard](/docs/componentes/dashboard) or [Report](/docs/componentes/reporte)

</Admonition>

## Variants {/* #modalidades */}

- **Interface-based search:** the user interacts with graphical fields and filters; typical of searches on websites and end-user applications
- **Language-based search:** the user writes queries in a formal or natural language (SQL, GraphQL, natural language)
- **Predefined search:** the system offers preloaded queries that the user only triggers, without composing the criteria
