## Description {/* #descripcion */}

A component that lets an authenticated user manage the essential data and security settings of their own account. The user can change access credentials, update contact information, and manage security aspects such as two-factor authentication or active sessions. Unlike the initial creation of an account, this component operates on an existing account and requires the user to be authenticated or able to verify their identity.

## Additional capabilities {/* #capacidades-adicionales */}

<div className={styles.capBlockOptional}>

<div className={styles.capHeading}>
  <svg viewBox="0 0 16 16" width="16" height="16" fill="currentColor"><path d="M8 1a7 7 0 1 1 0 14A7 7 0 0 1 8 1zm.5 3.5a.5.5 0 0 0-1 0V7.5H4.5a.5.5 0 0 0 0 1H7.5v3a.5.5 0 0 0 1 0V8.5h3a.5.5 0 0 0 0-1H8.5V4.5z"/></svg>
  <span>Additional capabilities</span>
</div>

- **Password recovery:** a flow accessible without authentication that lets users who lost access reset their password through a link or code sent by email/SMS
- **2FA setup:** lets the user enable or disable two-factor authentication and register their methods (authenticator app, phone number)
- **Active session management:** shows the user's open sessions on different devices and lets the user close them remotely
- **Additional verification for sensitive changes:** asks for identity confirmation (current password, code by email/SMS) before applying critical modifications such as a change of email or password

</div>

## Boundaries {/* #delimitaciones */}

<Admonition type="danger" title="What it is not">

- **Does not** create new accounts — that belongs to [Account Creation](/docs/componentes/creador-cuenta)
- **Does not** cover the administration of other people's accounts; it is specifically about the personal account
- **Does not** include system personalization preferences such as theme, language, or notifications

</Admonition>

## Variants {/* #modalidades */}

- **Self-service:** the user manages their own account without administrator intervention
- **Assisted:** an administrator or support staff makes changes to the user's account (less common, typically for access recovery)

## Typical dependencies {/* #dependencias-tipicas */}
