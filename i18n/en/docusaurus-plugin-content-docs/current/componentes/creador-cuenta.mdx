## Description {/* #descripcion */}

A component that lets people without an account in the system create their first user account. It presents an interface accessible without prior authentication, where the user provides their basic data or links their identity through other means. The system validates the information, creates the new account, and stores the credentials securely so that they can later be used to authenticate.

## Additional capabilities {/* #capacidades-adicionales */}

<div className={styles.capBlockOptional}>

<div className={styles.capHeading}>
  <svg viewBox="0 0 16 16" width="16" height="16" fill="currentColor"><path d="M8 1a7 7 0 1 1 0 14A7 7 0 0 1 8 1zm.5 3.5a.5.5 0 0 0-1 0V7.5H4.5a.5.5 0 0 0 0 1H7.5v3a.5.5 0 0 0 1 0V8.5h3a.5.5 0 0 0 0-1H8.5V4.5z"/></svg>
  <span>Additional capabilities</span>
</div>

- **Prior verification by email or SMS:** requires the user to confirm possession of the declared contact channel before the account is activated, through a code or link sent to their email or phone
- **Anti-spam captcha:** includes challenges to prevent automated sign-ups by bots
- **Manual administrator approval:** keeps the account in a pending state until an administrator explicitly approves it
- **Invitation code restriction:** limits registration to those who hold a previously issued code, controlling who can join the system

</div>

## Boundaries {/* #delimitaciones */}

<Admonition type="danger" title="What it is not">

- **Does not** authenticate the user after the account is created — that belongs to [Login Form](/docs/componentes/formulario-login)
- **Does not** modify existing accounts — that belongs to [Profile Management](/docs/componentes/gestion-perfil)
- **Is not** the administration of accounts by authorized staff

</Admonition>

## Variants {/* #modalidades */}

- **Traditional registration:** a form with email or username and password
- **SSO registration:** "Sign up with Google/Microsoft/Facebook", delegating the data to the provider
- **On-device registration:** linking the account to the device through fingerprint, PIN, or pattern (common in mobile apps)
