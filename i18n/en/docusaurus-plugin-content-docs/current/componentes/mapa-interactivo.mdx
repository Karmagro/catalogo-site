## Description {/* #descripcion */}

Presents information from the system on a dynamic geographic representation, allowing the user to explore the spatial distribution or location of entities that have associated location data. Unlike a static map, the interactive map lets the user actively explore the information through operations such as zooming, panning, or selecting elements to see more detail.

## Additional capabilities {/* #capacidades-adicionales */}

<div className={styles.capBlockOptional}>

<div className={styles.capHeading}>
  <svg viewBox="0 0 16 16" width="16" height="16" fill="currentColor"><path d="M8 1a7 7 0 1 1 0 14A7 7 0 0 1 8 1zm.5 3.5a.5.5 0 0 0-1 0V7.5H4.5a.5.5 0 0 0 0 1H7.5v3a.5.5 0 0 0 1 0V8.5h3a.5.5 0 0 0 0-1H8.5V4.5z"/></svg>
  <span>Additional capabilities</span>
</div>

- **Entity filtering:** lets the user restrict the entities displayed through defined criteria (category, value range, date)
- **Highlighting and selection:** visually highlights specific entities according to conditions, a search, or user interaction
- **Integrated search:** lets the user search for an entity and center the map on its location
- **Detail on click:** displays additional information about an entity when it is selected on the map
- **Configurable layers:** lets the user turn different representations on or off (traffic, satellite, political boundaries)

</div>

## Boundaries {/* #delimitaciones */}

<Admonition type="danger" title="What it is not">

- **Is not** [Queries](/docs/componentes/consultas): the purpose of Queries is to retrieve specific records according to search criteria; the purpose of the Interactive Map is to visualize the geographic distribution or location of entities
- **Is not** a [Dashboard](/docs/componentes/dashboard): its goal is not to present metrics or aggregate indicators about the state of a process or business

</Admonition>

## Variants {/* #modalidades */}

- **Marker map:** represents individual entities as points or icons positioned according to their location. It allows exploring the geographic distribution of concrete elements.
- **Heatmap:** visualizes the density or concentration of entities in geographic areas through color gradients, without distinguishing individual elements.
- **Choropleth map:** colors delimited geographic regions (countries, states, municipalities) according to the value of an aggregate attribute of the entities associated with each region.
