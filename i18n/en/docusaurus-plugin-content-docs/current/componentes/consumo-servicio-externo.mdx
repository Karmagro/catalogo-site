## Description {/* #descripcion */}

A component through which the system invokes a service provided by an external system in order to obtain information or delegate an operation that it does not handle by itself. The system acts as a client: it builds the request according to the third party's contract, sends it, and processes the response received to incorporate it into its own flow. It is the "client" side of an integration between systems, and it makes it possible to incorporate third-party capabilities (maps, payments, validations) without developing them internally.

## Additional capabilities {/* #capacidades-adicionales */}

<div className={styles.capBlockOptional}>

<div className={styles.capHeading}>
  <svg viewBox="0 0 16 16" width="16" height="16" fill="currentColor"><path d="M8 1a7 7 0 1 1 0 14A7 7 0 0 1 8 1zm.5 3.5a.5.5 0 0 0-1 0V7.5H4.5a.5.5 0 0 0 0 1H7.5v3a.5.5 0 0 0 1 0V8.5h3a.5.5 0 0 0 0-1H8.5V4.5z"/></svg>
  <span>Additional capabilities</span>
</div>

- **Failure handling and retries:** retries the invocation or applies a fallback when the external service does not respond or returns an error, preventing the external failure from disrupting the system
- **Caching of external responses:** temporarily stores the third party's responses to reduce repeated calls and dependence on its availability
- **Data transformation:** adapts the format of the external response to the system's internal data model
- **Integration monitoring:** records the latency, errors, and availability of the external service being consumed

</div>

## Boundaries {/* #delimitaciones */}

<Admonition type="danger" title="What it is not">

- **Does not** expose the system's own functionality to third parties — that belongs to [Exposed Service](/docs/componentes/servicio-expuesto): here the system is the one using someone else's service, not the one offering it
- **Does not** control or implement the external service: it depends on the contract and availability defined by the third party
- **Is not** a [Scraper](/docs/componentes/scraper): service consumption uses a formal, authorized contract provided by the third party; the Scraper extracts data from an interface not designed to be consumed programmatically
- **Is not** an [ETL](/docs/componentes/etl): although both bring in external data, the ETL runs planned bulk loads; service consumption invokes specific operations as the system needs them

</Admonition>

## Variants {/* #modalidades */}

- **Query consumption:** the system invokes the third party to obtain information (e.g., looking up an exchange rate, a location, a credit score)
- **Operation consumption:** the system invokes the third party to carry out an action (e.g., initiating a payment, sending an email through a provider)
- **REST / SOAP / GraphQL:** depending on the protocol defined by the external service being consumed

## Typical dependencies {/* #dependencias-tipicas */}

<div className={styles.dependencies}>

- An external service provided by a third party, with its contract and documentation
- Access credentials for the external service (API key, token, certificate) and their secure storage
- [API Authentication](/docs/componentes/autenticacion-api) to identify the system to the external service being consumed
- Network connectivity to the external system

</div>
