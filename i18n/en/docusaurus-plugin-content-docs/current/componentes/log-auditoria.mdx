## Description {/* #descripcion */}

Automatically and chronologically records the relevant actions performed within the information system, associating each event with a user, a date, and an affected entity. Its purpose is to keep a traceable and unalterable history of the system's activity, which makes it possible to answer the questions "who did what, when, and to what" with concrete evidence. It operates autonomously and in a cross-cutting way: recording happens without user intervention, for every action the system considers relevant.

## Mandatory capabilities {/* #capacidades-mandatorias */}

<div className={styles.capBlockMandatory}>

<div className={styles.capHeading}>
  <svg viewBox="0 0 16 16" width="16" height="16" fill="currentColor"><path d="M8 1a7 7 0 1 1 0 14A7 7 0 0 1 8 1zm3.36 4.65a.5.5 0 0 0-.72-.01L7.3 9.28 5.36 7.34a.5.5 0 1 0-.72.7l2.25 2.25a.5.5 0 0 0 .72 0l3.75-3.75a.5.5 0 0 0 0-.7z"/></svg>
  <span>Mandatory capabilities</span>

- Records events automatically, without requiring explicit action from the user
- Each entry includes at least: the user who performed the action, date and time, type of operation, and affected entity
- Entries are persistent and cannot be altered by regular users; they cannot be modified or deleted through the normal operation of the system
- Access to the log is restricted to profiles with specific permissions (administrators, auditors)

</div>

## Additional capabilities {/* #capacidades-adicionales */}

<div className={styles.capBlockOptional}>

<div className={styles.capHeading}>
  <svg viewBox="0 0 16 16" width="16" height="16" fill="currentColor"><path d="M8 1a7 7 0 1 1 0 14A7 7 0 0 1 8 1zm.5 3.5a.5.5 0 0 0-1 0V7.5H4.5a.5.5 0 0 0 0 1H7.5v3a.5.5 0 0 0 1 0V8.5h3a.5.5 0 0 0 0-1H8.5V4.5z"/></svg>
  <span>Additional capabilities</span>

- **Before and after state storage:** saves the values before and after each modification, making it possible to reconstruct how the information evolved
- **Entry export:** allows downloading the log entries for external analysis or regulatory compliance
- **Built-in viewer:** provides an interface for authorized users to browse the history directly from the system
- **Configurable retention:** defines how long entries are kept before they are automatically purged

</div>

## Boundaries {/* #delimitaciones */}

<Admonition type="danger" title="What it is not">

- **Is not** a system log: system logs record technical and operational events (errors, restarts, performance); the Audit Log records user actions and changes to business data
- **Is not** a [Notification System](/docs/componentes/sistema-notificacion): the log records silently; it does not alert or communicate events to external recipients
- **Is not** a [Report](/docs/componentes/reporte): although the log data can be queried or exported, the component itself does not consolidate or process the information for analytical purposes

</Admonition>

## Variants {/* #modalidades */}

- **Access log:** records every successful or failed login attempt
- **Change log:** records modifications to the system's data (creation, editing, and deletion of records)
- **Operations log:** records administrative and configuration actions on the system
