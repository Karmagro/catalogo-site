## Description {/* #descripcion */}

A component that goes through web pages or documents to identify and extract specific information from their content. Its function is to obtain data from unstructured or semi-structured sources through techniques such as pattern matching or parsing, and to hand it over to the system for storage or later processing. Unlike components that consume formal APIs, the scraper accesses the content of the pages or documents directly, searching for, identifying, and extracting the relevant data according to predefined criteria.

## Additional capabilities {/* #capacidades-adicionales */}

- **Working together with a crawler:** receives URLs discovered dynamically by a component that navigates by following links, instead of operating on a predefined list of sources
- **Manual trigger:** lets an authorized user start the extraction on demand
- **Periodic scheduling:** runs the scraping at defined intervals
- **Extraction logging:** records runs, success rates per source, and the data actually extracted
- **Tolerance to structural changes:** implements multiple selectors or fallback strategies that mitigate the effect of changes to the source pages

</div>

## Boundaries {/* #delimitaciones */}

<Admonition type="danger" title="What it is not">

- **Is not** a crawler: it does not navigate by following links or discover content on its own; it requires specific URLs or locations as input
- **Is not** an [ETL](/docs/componentes/etl): the ETL consumes structured data from APIs or databases; the scraper extracts data from unstructured content
- **Does not** transform or process the extracted data in depth; it only identifies it and hands it over
- It may stop working if the structure of the sources changes and there is no tolerance to those changes

</Admonition>

## Variants {/* #modalidades */}

- **Web scraping:** extraction of data from HTML pages through CSS selectors, XPath, or other DOM parsing mechanisms
- **Document scraping:** extraction of data from files with unstructured or semi-structured content (PDF, Word, spreadsheets without a standard format)

## Typical dependencies {/* #dependencias-tipicas */}

<div className={styles.dependencies}>

- External sources to process (web pages, documents accessible by URL)
- Selectors or rules that define what to extract from each source
- [Database](/docs/componentes/base-datos) or another component that receives the extracted data
- A scheduling mechanism or scheduler for periodic runs, when that capability is present

</div>
