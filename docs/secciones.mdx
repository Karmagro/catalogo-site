# Componentes por Sección del Tablero

La matriz muestra qué componentes del catálogo se vinculan con cada una de las seis secciones del Tablero Digital, y con qué carácter: mandatorio, opcional o sin vínculo.

Un vínculo **mandatorio** significa que el componente siempre toca esa sección por sus capacidades esenciales. Un vínculo **opcional** indica que la toca solo cuando incorpora ciertas capacidades adicionales. Una celda vacía significa que el componente no se vincula con esa sección ni en su forma mandatoria ni en sus variantes opcionales documentadas.

## Cómo leer la matriz

Responde a preguntas como:

- *¿Qué componentes actualizan datos del sistema mediante operadores humanos?* → Revisa la columna **Act. Manual**
- *¿Qué componentes producen salidas automáticas?* → Revisa la columna **Salidas A.**
- *¿Qué secciones del tablero toca un Dashboard?* → Recorre la fila de **Dashboard**.

## Lectura por sección

A continuación se presentan los componentes agrupados según cada sección del tablero, con el carácter mandatorio u opcional de cada vínculo.

<Tabs>
<TabItem value="actualizacion-manual" label="Actualización Manual">

**Mandatorios (3):** Creador de Cuenta, Gestión de Perfil, Mantenedor

**Opcionales (2):** Sistema de Notificación, Autorización

Estos componentes permiten que un operador humano cree, modifique o elimine datos que el sistema mantiene de forma persistente, mediante formularios, pantallas de edición u otros mecanismos análogos.

</TabItem>
<TabItem value="actualizacion-automatica" label="Actualización Automática">

**Mandatorios (4):** Autenticación API, ETL, Scraper, Consumo de Servicio Externo

**Opcionales (1):** Servicio Expuesto

Estos componentes incorporan o actualizan información en el sistema sin intervención humana directa, de forma periódica o reactiva ante eventos externos.

</TabItem>
<TabItem value="conceptos" label="Conceptos de Datos">

**Mandatorios (18):** todos los componentes del catálogo

**Opcionales (0):** Ninguno

Todos los componentes del catálogo involucran conceptos de datos. Esta es la sección de mayor cobertura: siempre hay entidades del sistema que el componente lee, escribe o referencia.

</TabItem>
<TabItem value="salidas-demanda" label="Salidas por Demanda">

**Mandatorios (6):** Gestión de Perfil, Mantenedor, Dashboard, Consultas, Reporte, Mapa Interactivo

**Opcionales (1):** Log de Auditoría

Estos componentes entregan información al usuario cuando este la solicita explícitamente.

</TabItem>
<TabItem value="salidas-automaticas" label="Salidas Automáticas">

**Mandatorios (3):** Sistema de Notificación, Servicio Expuesto, Consumo de Servicio Externo

**Opcionales (5):** Formulario de Login, Login Biométrico, Creador de Cuenta, Gestión de Perfil, Reporte

Estos componentes comunican información de manera proactiva, sin solicitud del usuario.

</TabItem>
<TabItem value="procesos-autonomos" label="Procesos Autónomos">

**Mandatorios (10):** Autenticación API, Dashboard, Sistema de Notificación, ETL, Scraper, Reporte, Log de Auditoría, Servicio Expuesto, Consumo de Servicio Externo, Autorización

**Opcionales (3):** Login Biométrico, Mantenedor, Base de Datos

Estos componentes ejecutan tareas en segundo plano, de forma programada o reactiva.

</TabItem>
</Tabs>
